Backup & Restore

Create comprehensive database backups and restore your school data to a perfect state even after re-running the schema from scratch.

Create Backup

Downloads a complete JSON snapshot of all your school data — students, teachers, exams, scores, attendance, fees, receipts, grading systems, and more. This file contains everything needed to restore your school to its exact current state.

Tip: Keep this backup file safe. After re-running the schema from scratch, you can restore this backup to get back to a perfect state.

Restore Backup

Restore your school data from a backup file. This will delete all existing data for the tables in the backup and replace them with the backed-up records. IDs are preserved so all relationships (exams → results, teachers → classes, fees → receipts, etc.) remain intact.

TableLabelRecordsStatus
Total Records: 0

ℹ About Backup & Restore

What is backed up? All school data tables including: students (applications), teachers, accountants, classes, subjects, exams, exam results, exam subjects, exam student details, attendance, announcements, parent links, fee categories, class fees, student fees, payment transactions, receipts, teacher class-subject assignments, teacher documents, grading systems, settings, sub admins, sub admin activities, school module locks, and more.

How does restore work? The restore process:

  1. Deletes existing data in reverse dependency order (children first)
  2. Re-inserts backup data in forward dependency order (parents first)
  3. Preserves original IDs so foreign key relationships remain valid
  4. Verifies the restore by comparing student counts

After re-running the schema: Simply log in as your school admin, go to Backup & Restore, select your backup file, and click "Confirm & Restore". Your data will be restored to the exact state when the backup was created.
